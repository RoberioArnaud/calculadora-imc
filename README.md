# Calculadora de IMC

Projeto da disciplina de Cultura e Práticas DevOps. O objetivo é desenvolver uma calculadora simples de Índice de Massa Corporal (IMC) e praticar o desenvolvimento em pequenas etapas, com commits ao longo do processo.

## Tecnologias previstas

- HTML, CSS e JavaScript puro para a calculadora.
- Git e GitHub para controle de versão.
- GitHub Actions para automação e CI/CD.
- GitHub Pages para publicação.
- SAST e DAST para análise de segurança.

Neste momento, o repositório contém apenas este README. A calculadora e as demais configurações serão adicionadas nas próximas etapas.
